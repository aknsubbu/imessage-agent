# Brand assets

The logo is a speech bubble holding a spark: a message with something thinking behind it. It is original, not a copy of Apple's Messages icon, and the SVGs use no fonts or scripts, so they render the same in a README, a browser tab or a social card.

| File | Use |
|---|---|
| [`logo.svg`](logo.svg) | The mark on a rounded square. Used in the README banner and at the top of each doc. |
| [`logo-square.svg`](logo-square.svg) | The same mark, full-bleed with square corners, for places that round it themselves (a contact photo, an app icon). |
| [`logo-1024.png`](logo-1024.png), [`logo-512.png`](logo-512.png) | PNGs of the square version. Use `logo-1024.png` as the agent's contact photo. |
| [`banner.svg`](banner.svg) | The wide image at the top of the main README (1280×360, its own dark background, so it reads on both light and dark GitHub themes). |
| [`social-preview.svg`](social-preview.svg), [`social-preview.png`](social-preview.png) | The 1280×640 card GitHub shows when the repo is linked. Upload the PNG under Settings, then Social preview. |

The PNGs were exported from the SVGs; if you change an SVG, export it again.
